# TC2005B Software Construction and Decision Making

This repository contains the work for the TC2005B assignment, organized into three separate branches, each dedicated to a specific purpose:

## Branches

- **web**: Contains all code and resources related to the web development portion of the assignment. This includes HTML, CSS, JavaScript, and any web assets.
- **game**: Contains the Unity project and all related files for the game development portion of the assignment.
- **database**: Contains scripts, schemas, and documentation for the database portion of the assignment.

## Workflow

- Changes and updates are submitted to the branch that corresponds to the current area of work (web, game, or database).
- Each branch is maintained independently to keep the work organized and focused on its specific purpose.

## How to Use

1. **Clone the repository**:
   ```sh
   git clone https://github.com/Dylan-Uribe/TC2005B.git
    ```
2. Switch to the desired branch
    ```sh
    git checkout web      # For web development
    git checkout game     # For game development
    git checkout database # For database work
    ```
## Structure

- web/ -Web assignment files
- Game/ -Unity game project files
- database/ -Database scripts and documentation
