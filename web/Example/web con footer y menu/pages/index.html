Bienvenido a MiSitio

Este es un ejemplo con header y footer cargados dinámicamente.

El link “Inicio” del menú deberá verse activo en esta página.

¿Cómo funciona?

  1. En cada página ponemos contenedores con data-include apuntando a los partials.
  2. assets/app.js busca esos contenedores, hace fetch y inyecta el HTML.
  3. El script también marca el link activo del menú y rellena el año del footer.
